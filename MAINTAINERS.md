# Maintainers

OpenAEO is currently maintained by:

- `@marioledger` - primary maintainer

## Maintainer Responsibilities

- Review pull requests for correctness, security, and attribution-first behavior.
- Triage bug reports, rule requests, and site compatibility issues.
- Keep CI, dependencies, release notes, and security guidance current.
- Reject features that encourage spam, cloaking, abusive crawling, or ranking manipulation.

## Review Expectations

Security-sensitive changes to crawling, URL handling, API routes, report exports, or OpenAI API usage should receive maintainer review before release.
